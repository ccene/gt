# Your Solutions
Add your completed code here as you work through the 3-day plan.

## 📁 Structure
Create subfolders for each day:
```
SOLUTIONS/
├── day1/
│   ├── functions/
│   ├── bicep/
│   └── devops/
├── day2/
│   └── angular-app/
└── day3/

```

## 📌 How to Use
1. After completing a task, copy your final code to the corresponding folder.
2. Commit your solutions:
   ```bash
   git add SOLUTIONS/
   git commit -m "Day 1: Completed Azure backend tasks"
   git push
   ```
3. Use this as a reference for your interview.
