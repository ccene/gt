# Grant Thornton Senior Engineer Interview Prep

**3-day hands-on plan** to master Azure, Angular, and AI for your interview.
**Learn by doing**—clone this repo, follow the tasks, and build a full-stack system.

---

## 🚀 Quick Start
1. **Prerequisites**:
   - [Azure Account](https://azure.microsoft.com/) (Free tier OK)
   - [Azure CLI](https://learn.microsoft.com/en-us/cli/azure/install-azure-cli)
   - [Node.js 18+](https://nodejs.org/)
   - [Angular CLI](https://angular.io/cli) (`npm install -g @angular/cli`)
   - [Git](https://git-scm.com/)

2. **Clone & Setup**:
   ```bash
   git clone https://github.com/ccene/grant-thornton-interview-prep.git
   cd grant-thornton-interview-prep
   ```

3. **Follow the plan**:
   - [Day 1: Azure Backend & Infrastructure](./backend/README.md)
   - [Day 2: Frontend & Integration](./frontend/README.md)
   - [Day 3: AI & Polish](./ai/README.md)

---

## 📅 3-Day Schedule
| Day | Focus | Deliverable |
|-----|-------|-------------|
| 1 | Azure Backend | Serverless order system (Functions + Service Bus + Event Grid + Key Vault) + Bicep + CI/CD |
| 2 | Frontend | Angular app + backend integration + state management + auth |
| 3 | AI + Polish | AI tests/reviews + performance + security + mock interview |

---
## 🎯 Interview Focus Areas
- **Azure**: Functions, Service Bus, Event Grid, Key Vault, Bicep, DevOps
- **Frontend**: Angular, RxJS, state management, testing
- **AI**: Code generation, testing, reviews, automation
